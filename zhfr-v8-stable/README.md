# 中法同传 v8 Stable Turn

v8 的目标是可靠性，而不是极限低延迟。

流程：
1. 浏览器持续监听麦克风，并在本地检测开口/停顿。
2. 一句话结束后，将该小段音频发送到服务器。
3. `gpt-transcribe` 使用 `languages=["zh","fr"]` 自动检测中文或法语，并返回原文和语言代码。
4. `gpt-5.6-luna` 根据检测到的语言做严格文本翻译：
   - 中文 → 法语
   - 法语 → 简体中文
5. 可选语音朗读使用浏览器/手机系统 TTS，不调用收费的语音输出 API。

为什么不用单个 Realtime 会话自动双向翻译：
开源 realtime-translate-interface 的稳定模式是“源语言可自动检测 + 目标语言固定”。把目标语言也动态改成“另一种语言”会产生输出方向漂移或响应错配。v8 把语言检测和翻译拆开，方向是确定性的。

成本：
- `gpt-transcribe` 当前标价约 $0.0045/分钟音频。
- 文本翻译使用 GPT-5.6 Luna，短句成本通常非常低。
